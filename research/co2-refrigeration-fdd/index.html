Robust Fault Detection in CO2 Refrigeration Systems

Optimal sensor selection and robustness analysis using tree-based machine learning.

Read the Paper

Overview

This study develops data-driven Fault Detection and Diagnosis models for a laboratory-scale CO2 refrigeration system used in supermarket applications. The models classify six common faults while aiming to reduce the number of sensors required for reliable monitoring.

The work also evaluates how sensor noise and the failure of a critical sensor affect diagnostic performance, connecting model accuracy with practical reliability.

Method

Tree-Based Models

Random Forest, XGBoost, CatBoost, and LightGBM classify normal operation and six refrigeration-system fault conditions.

Sensor Selection

Recursive Feature Addition ranks sensors and incrementally selects the smallest set needed to reach the target F1-score.

Robustness Analysis

Additive White Gaussian Noise is injected into test data at different SNR levels to evaluate model resilience.

↗ PROPOSED WORKFLOW

Optimal sensor selection and robustness analysis

The workflow combines model training, performance evaluation, and noise testing in an iterative sensor-selection loop. Sensors are added according to their feature-importance ranking until the F1-score reaches the 99% stopping criterion.

  1. Start with the original sensor dataset.
  2. Split the data into training and unnoisy testing sets.
  3. Train the classifier using the current sensor subset.
  4. Inject AWGN into the most important sensor in the test set at SNR = 3 dB.
  5. Compare performance without noise and robustness with noise.
  6. Add the next ranked sensor if the F1-score is below 99%; stop when the threshold is achieved.

Case Study

CO2 — 43 kW

Laboratory-Scale Refrigeration System

The two-stage CO2 refrigeration system provides low- and medium-temperature cooling with a total capacity of 43 kW. The study uses experimental data from normal operation and six fault conditions.

24 Temperature Sensors 7 Pressure Sensors 3 Mass-Flow Sensors 6 Power Sensors
DATA — 75 / 25

Fault Classes and Dataset Preparation

The dataset contains normal operation, an open LT display case door, ice accumulation, LT expansion-valve failure, MT evaporator fan failure, condenser air-path blockage, and MT evaporator air-path blockage. After undersampling the majority class, the data were split into 75% training and 25% testing sets.

Results

XGBoost achieved the strongest robustness

The models reached approximately 99% F1-score using compact sensor sets: 4 sensors for Random Forest, 7 for XGBoost, and 5 sensors for both CatBoost and LightGBM.

XGBoost achieved 99.25% F1-score and 85.24% robustness at an SNR of 3 dB. Its robustness increased to 90.23% at 10 dB and remained at 79% when the most important sensor was completely unavailable.

The results show a practical trade-off: fewer sensors reduce cost, while a broader sensor set improves resilience to noise and sensor failure.

High-Quality Signal

At SNR = 10 dB, XGBoost robustness increased to 90.23%, while CatBoost and LightGBM reached 57.84% and 50.71%.

Worst-Case Noise

At SNR = 0 dB, XGBoost retained 83.83% robustness, showing the benefit of its broader seven-sensor configuration.

Critical Sensor Failure

When the most important sensor failed, XGBoost retained 79% robustness, compared with 37% for Random Forest, 44% for CatBoost, and 41% for LightGBM.
